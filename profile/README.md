Glim is a free, open-source file viewer for macOS, supporting Apple Silicon and Intel. Read Markdown, source code, PDFs, images and structured data in one workspace. Review Git diffs, stage changes and commit staged content; make basic edits to ordinary UTF-8 files.

Glim 是免费开源的 macOS 文件查看器，支持 Apple Silicon 与 Intel。在一个工作空间阅读 Markdown、源码、PDF、图片和结构化数据，查看 Git 差异、暂存改动并提交已暂存内容，也可基础编辑普通 UTF-8 文件。
